# Travelling-Wave Analysis of a Two-Component Reaction-Diffusion Model of Cell Invasion

Supporting code for MSc dissertation, University of Edinburgh, 2026.

## Repository contents

`scripts/` - Python scripts to generate all figures and numerical results.
`figures/` - Figures generated by the scripts and included in the dissertation
`data/` - Numerical output CSV files.


## Requirements

Install the required Python packages with

```bash
pip install -r requirements.txt
```
